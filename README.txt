NINJA Full Web Assets Pack

This package includes a clean `/public/assets` structure for React / Next.js implementation.

Included:
- High-quality transparent PNG assets
- SVG backgrounds and dividers
- Service icons
- Process icons
- Brand assets
- UI icons
- asset-manifest.json
- design-tokens.css

Usage:
Copy the `public/assets` folder into your app, then use paths like:
- /assets/hero/hero-composition-crystal-devices.png
- /assets/mockups/laptop-mockup-dark-ui.png
- /assets/decor/crystal-shard-cluster.png
- /assets/backgrounds/section-wave-light.svg
